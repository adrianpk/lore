# Lore User Guide

This guide builds one local activity journal and connects a Git workspace to
it. Follow the chapters in order for the first setup.

1. [Install and activate Lore](01-install-and-activate.md).
2. [Connect a workspace agent](02-connect-a-workspace-agent.md).
3. [Record and retrieve activity](03-record-and-retrieve-activity.md).

After the guided path, use the [how-to guides](../../how-to/index.md) for
focused tasks, the [reference](../../reference/index.md) for exact behavior,
and the [explanation](../../explanation/index.md) for the activity model.
