# Lore Documentation

These documents describe the current journal-oriented technical foundation.
They will evolve with the knowledge capture, retrieval, review, and pruning
contracts as those behaviors replace the baseline activity model.

Start with the [Lore user guide](tutorials/user-guide/index.md) to install the
local service, connect a workspace agent, and record and retrieve typed
activity.

Use the documentation by intent after the guided path:

- [Tutorials](tutorials/index.md) teach a complete first-use workflow.
- [How-to guides](how-to/index.md) solve focused operating tasks.
- [Reference](reference/index.md) defines commands, stored data, limits, and
  exact behavior.
- [Explanation](explanation/index.md) describes the activity model and how to
  interpret recorded facts.
